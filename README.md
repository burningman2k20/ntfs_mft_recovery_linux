# NTFS MFT Recovery for Linux

NTFS Master File Table Recovery for linux. Was not able to find any useful app to recover folder structure and files for either linux or windows, so i made my own.

This application looks at the MFT data of specified device or disk image file, and finds and allows to extract files and folders, with original folder structure, even if drive is unreadable/unmountable. Handles NTFS compression for files and folders.

Used Google AI Studio to help create this.
